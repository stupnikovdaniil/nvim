# Neovim

Личный конфиг для работы с клавиатуры. Проверен на Neovim 0.11.4.
Leader — `Space`. Мышь отключена. Дерево открывается по команде.

## Установка и зависимости

Положить конфиг в `stdpath("config")` (обычно `~/.config/nvim`), запустить `nvim`.
Lazy устанавливается автоматически; `:Lazy restore` восстанавливает версии плагинов
из `lazy-lock.json`. После обновления плагинов нужно перезапустить Neovim.

Нужны Git и `rg` (ripgrep). Для иконок нужен Nerd Font в терминале.
`make` и C-компилятор нужны для необязательного ускорения Telescope через fzf-native.
Mason устанавливает указанные в `lua/plugins/lsp.lua` языковые серверы;
их установщикам могут потребоваться Node.js/npm, Python/pip, Go и другие инструменты.
Проверка состояния: `:checkhealth`, `:Mason`, `:ConformInfo`.

Форматтеры устанавливаются отдельно; Mason LSP их автоматически не устанавливает:

| Файлы | Форматтеры |
| --- | --- |
| Lua | `stylua` |
| Python | `ruff` либо `isort` + `black` |
| JS, TS, JSON, YAML | `prettierd` либо `prettier` |
| Markdown | `mdformat` |
| Go | `gofumpt` + `goimports` |
| Rust | `rustfmt` |
| Shell | `shfmt` |
| TOML | `taplo` |
| Terraform/HCL | `terraform fmt` |
| SQL | `sqlfluff`, диалект PostgreSQL |

Если форматтер не найден, Conform пробует форматирование через подключённый LSP.
Сохранение файлов до 512 КиБ форматируется синхронно, более крупных — после сохранения.

## Навигация

| Сочетание | Действие |
| --- | --- |
| `Space` + буква на верхней панели | Перейти к буферу |
| `Space h` / `Space l` | Предыдущий / следующий буфер |
| `Space Space w` / `Space Space W` | Закрыть буфер / закрыть без сохранения |
| `Space pp` | Закрепить файл в pinbar текущего окна |
| `Space 1…9` | Перейти к закреплённому файлу |
| `Space d1…d9` | Убрать закрепление |
| `Space e` / `Space E` | Открыть или сфокусировать дерево / закрыть дерево |
| `Space tf` / `Space tt` | Метки дерева: открыть файл / перейти к строке |
| `Ctrl-p` / `Space ff` | Поиск файла проекта / поиск файлов |
| `Space fg` / `Space fb` | Поиск текста / буферов |
| `Ctrl-h/j/u/l` | Перейти в окно слева / снизу / сверху / справа |
| `Space ws/wv/wc/w=` | Горизонтальный сплит / вертикальный / закрыть / выровнять |
| `Space gs` / `Space gd` | Git status / diff |
| `Space xx` / `Space xd` | Диагностика проекта / текущего файла |
| `gd` / `gr` / `K` | Определение / ссылки / справка LSP |
| `Space rn` / `Space ca` | Переименовать символ / code action |
| `Space u` | История undo |
| `Space sr/st/sg` | Rose Pine / Tokyo Night / Gruvbox |

Буква принадлежит буферу до его закрытия; перестановка и закрытие соседних буферов
её не меняют. Освободившаяся буква используется повторно. Метки действуют в пределах
сеанса, между запусками не сохраняются. Если букв не хватает, появляются метки
`zk`, `zj` и далее: после `Space` нужно набрать всю метку. `Esc` отменяет ввод.

В дереве: `h/l` — свернуть/открыть, `n` — создать, `r` — переименовать,
`dd` — удалить, `yy/p` — скопировать/вставить. `zr` раскрывает текущую папку
рекурсивно, `zR` — всё дерево, `zM` — сворачивает. `Esc` возвращает в предыдущее окно.

## Форматирование

| Команда или сочетание | Область действия |
| --- | --- |
| `Space cf` / выделение + `Space cF` | Форматировать вручную |
| `Space ct` | Включить/выключить автоформат глобально |
| `Space cT` | Включить/выключить автоформат текущего буфера |
| `:FormatDisable` / `:FormatEnable` | Выключить/включить для текущего буфера |
| `:FormatDisable!` / `:FormatEnable!` | Выключить/включить глобально |
| `:FormatStatus` | Показать оба флага и итоговое состояние |

Автоформат работает, когда включены оба уровня. Глобальное переключение сохраняет
индивидуальные настройки файлов. В статусной строке `fmt:on` / `fmt:off` показывает
итоговое состояние текущего буфера. Ручное форматирование работает независимо от флагов.

## Изменение конфига

- `init.lua` — общие параметры и запуск собственных модулей.
- `lua/config/keys.lua` — пользовательские сочетания и группы Which-key.
  Добавлять новые сочетания нужно сюда: генератор автоматически исключит занятые
  буквы, а проверка обнаружит дубли и конфликтующие префиксы.
- `lua/buffer_labels.lua`, `lua/pinbar.lua`, `lua/neo_tree_hints.lua` — навигация.
- `lua/config/formatting.lua` — состояние автоформата.
- `lua/config/tree.lua` — действия с деревом.
- `lua/plugins/` — спецификации и настройки плагинов, включая их локальные меню.

`Space z` зарезервирован для длинных меток. Если он занят, используется `Space Z`;
не следует занимать оба сочетания. Метки назначаются заново при перезапуске после
изменения набора клавиш. `h` и `l` всегда исключаются благодаря записям навигации.

## Проверки и измерения

После установки плагинов, из корня проекта:

```sh
sh scripts/check.sh
sh scripts/check.sh --profile
```

Проверяются Lua-синтаксис, конфликты клавиш, стабильность меток после удаления
и перестановки, повторное использование букв, короткие и длинные переходы,
pinbar, оба уровня автоформата, большие файлы, LSP-конфигурация и первая загрузка дерева.
Для `tf` и `tt` запускаются отдельные процессы: до нажатия дерево не загружено.

Проверки используют временные data/cache/state и уже установленные плагины,
не устанавливают и не обновляют зависимости. Обновление реестра Mason отключено.
Запуск языковых серверов и полноценная работа терминального интерфейса не проверяются.

`--profile` делает пять замеров загрузки конфига в headless-режиме и показывает число
загруженных плагинов. Первый замер включает заполнение временного кеша.
Это не время готовности LSP и не измерение отзывчивости интерфейса.
Для разбора задержек в обычной сессии использовать `:Lazy profile`, `:ConformInfo`
и `:checkhealth`.
